Dúvidas sobre automações

O Agente confirma se o cliente pagou?

O histórico do disparo mostra se o contato foi enviado, entregue, respondido ou falhou. Para confirmar pagamento, o Agente precisa consultar uma fonte de dados do seu sistema que traga essa informação.

Posso fazer uma cobrança por ligação?

Sim. Escolha ligação telefônica no disparo, defina o roteiro e use uma linha de telefone configurada. O Agente conversa em tempo real e registra a transcrição. Ligação pelo WhatsApp ainda não está disponível.

O acompanhamento para quando a pessoa responde?

Sim, em uma jornada de WhatsApp configurada para isso. Os próximos contatos também param se a pessoa pedir para sair ou se a conversa for encerrada.

Quanto custa automatizar uma rotina?

As execuções usam créditos da conta. Mensagens ativas e ligações têm custos do canal; no disparo você vê uma estimativa antes de começar e depois acompanha o consumo realizado. Veja os detalhes de preço →
