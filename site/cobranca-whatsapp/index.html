O problema

Cobrar na mão toma o tempo de quem atende

Lembrar cada cliente no dia certo, voltar a falar com quem não respondeu e saber quem já foi avisado costuma ficar em planilha e em memória. O contato atrasa, o tom varia e ninguém enxerga o andamento de cada pessoa.

Da lista ao resultado, com você no controle

  1. 1
    Revise os contatos

    Cole os contatos ou importe uma lista CSV. Confira telefones, valores, vencimentos e a lista de não perturbe.

  2. 2
    Escolha a mensagem

    Escreva o texto com variáveis como o nome do cliente, veja a prévia e agende o horário. O custo estimado aparece antes do envio.

  3. 3
    Acompanhe as respostas

    O Agente conversa com quem responder. Com uma jornada configurada, o acompanhamento segue só para quem não respondeu e para quando a pessoa responde ou pede para sair.

  4. 4
    Veja o andamento

    Consulte envios, respostas, falhas e custo por contato.

Perguntas frequentes

Dúvidas sobre este caso de uso

O Agente confirma se o cliente pagou?

O histórico do disparo mostra se o contato foi enviado, entregue, respondido ou falhou. Para confirmar pagamento, o Agente precisa consultar uma fonte de dados do seu sistema que traga essa informação.

O acompanhamento para quando a pessoa responde?

Sim, em uma jornada de WhatsApp configurada para isso. Os próximos contatos também param se a pessoa pedir para sair ou se a conversa for encerrada.

Posso mandar a cobrança para todos os clientes de uma vez?

Sim. Você sobe uma lista em CSV e envia mensagens personalizadas pelo seu número oficial, sempre para quem autorizou receber suas mensagens. Para falar primeiro com quem não conversa com você há mais de 24 horas, use um modelo aprovado pela Meta.

Como é cobrado o envio das mensagens?

As mensagens ativas usam créditos da conta e são cobradas por mensagem enviada. No disparo você vê uma estimativa antes de começar e depois acompanha o consumo realizado.
